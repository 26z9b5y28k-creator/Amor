# Para o meu amor ♡

Site romântico interativo, sem dependências de JavaScript externas.

## Estrutura
- `index.html`
- `style.css`
- `script.js`
- `musica.mp3`
- `foto-1.jpeg` ... `foto-7.jpeg`

## Como abrir
Abra `index.html` no navegador.

## Música
A música é iniciada pelo primeiro toque no botão "entrar na nossa história" ou no botão "som". Isso evita o bloqueio de reprodução automática dos navegadores, especialmente no iPhone.

Se publicar em GitHub Pages/Netlify/etc., mantenha a pasta `assets` exatamente como está.
